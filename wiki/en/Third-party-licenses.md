# Third-party licenses

Gestionale Libreria is released under the MIT license, but the program is
not only its own code: it embeds 1054 components written by other people —
570 from the Rust world and 484 from the JavaScript world — and each one
belongs to its authors, under the license they chose.

**The full notices live in a single file:** [AVVISI-LICENZE.txt](https://raw.githubusercontent.com/alexkill536ita/gestionale-libreria/HEAD/AVVISI-LICENZE.txt).
It holds every component — name, version and declared license — and the
525 distinct notices exactly as their authors wrote them, one for each
different text: the one a hundred components repeat word for word appears
once.

**The same file travels with the program**, so there is no need to come
back here: the installer puts it next to the executable, on Windows in
`%LOCALAPPDATA%\Gestionale Libreria\` and on macOS inside
`Gestionale Libreria.app/Contents/Resources/`.

For 53 components there is no license file inside the package: they are
still listed with the license they declare, and nothing has been written on
their behalf.

The list is rebuilt at every release from the files that pin the dependency
versions: it describes the version you downloaded, not a snapshot typed by
hand.
